# 생물정보학실험 실습 저장소

이 저장소는 생물정보학실험 수업의 실습 공간이다.
Codespaces로 열면 파이썬과 생물정보학 도구가 이미 설치된 리눅스 환경이 준비된다.

## 시작하기

1. 초록색 `Code` 버튼 → `Codespaces` 탭 → `Create codespace on main`
2. 2~3분 기다린다. 처음 한 번만 오래 걸린다.
3. 아래 터미널에 환경 확인 결과가 자동으로 표시된다.

## 폴더 규칙

주차마다 `lab03`, `lab04` 처럼 폴더를 만들고, 그 안에 아래 세 폴더를 둔다.

| 폴더 | 넣는 것 |
|------|---------|
| `data` | 내려받거나 만들어 낸 데이터 파일 |
| `doc`  | 보고서, 결과 요약, 그림 |
| `src`  | 직접 작성한 스크립트 (`.sh`, `.py`) |

```
$ mkdir -p lab03/data lab03/doc lab03/src
```

## 매 실습이 끝나면

작업 내용을 저장소에 올린다.

```
$ git add .
$ git commit -m "lab03 완료"
$ git push
```

그리고 화면 **왼쪽 아래**의 Codespaces 표시를 눌러 `Stop Current Codespace` 를 선택한다.
창을 그냥 닫으면 한동안 켜져 있으면서 무료 사용 시간이 소모된다.

## 주의

- `data` 폴더의 시퀀싱 데이터는 자동으로 저장소에서 제외된다(`.gitignore`).
  용량이 크기 때문이며, 필요하면 명령어로 다시 내려받는다.
- 조립·주석 결과 폴더도 제외 대상이다. 결과는 화면 캡쳐로 보고서에 남긴다.
